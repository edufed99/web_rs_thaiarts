# แบบออกแบบคู่มือการใช้งานระบบแนะนำชุดการแสดงนาฏศิลป์ไทย

วันที่อนุมัติแบบ: 22 สิงหาคม 2569

ระบบอ้างอิง: https://thaiperform.fed.bpi.ac.th

ชื่อระบบบนเว็บไซต์: Thai Performing Arts Recommendation System / ThaiPerform AI

## 1. วัตถุประสงค์

จัดทำคู่มือการใช้งานระบบฉบับเดียวที่ครอบคลุมผู้เยี่ยมชม สมาชิก และผู้ดูแลระบบ โดยเรียบเรียงตามภารกิจที่ผู้ใช้ต้องทำจริง คู่มือต้องช่วยให้ผู้ใช้ใหม่ทำตามได้ทีละขั้น และช่วยให้ผู้ใช้เดิมค้นหาวิธีใช้งานเฉพาะเรื่องได้รวดเร็ว

## 2. ผลลัพธ์ที่ส่งมอบ

- ไฟล์ Microsoft Word นามสกุล `.docx` ซึ่งแก้ไขข้อความ ตาราง และภาพประกอบได้
- ขนาดหน้า A4 แนวตั้ง
- มีภาพหน้าจอจากเว็บไซต์ที่ใช้งานจริง พร้อมหมายเลขกำกับจุดสำคัญ
- มีสารบัญอัตโนมัติ เลขหน้า หัวกระดาษ และข้อมูลเวอร์ชันเอกสาร
- ความยาวเป้าหมายประมาณ 25-35 หน้า โดยปรับตามจำนวนภาพที่จำเป็นต่อความเข้าใจ

## 3. กลุ่มผู้อ่านและขอบเขต

### 3.1 ผู้เยี่ยมชม

- รู้จักหน้าแรกและเมนูหลัก
- ค้นหาชุดการแสดง
- เลือกดูตามหมวดหมู่และโอกาสสำคัญ
- ดูรายการยอดนิยม รายการที่ได้รับคะแนนสูง และรายละเอียดชุดการแสดง
- ขอคำแนะนำจากระบบ
- สมัครสมาชิก เข้าสู่ระบบด้วยอีเมลหรือ Google และตั้งรหัสผ่านใหม่

### 3.2 สมาชิก

- จัดการและแก้ไขข้อมูลโปรไฟล์
- ดูคำแนะนำเฉพาะบุคคล
- บันทึกรายการและดูรายการโปรด
- ให้คะแนนชุดการแสดงและดูประวัติการให้คะแนน
- ดูรายการที่เปิดดูล่าสุดและประวัติกิจกรรม
- ออกจากระบบ

### 3.3 ผู้ดูแลระบบ

- ดู Dashboard และสถิติการใช้งาน
- วิเคราะห์ข้อมูล
- เพิ่ม แก้ไข และลบชุดการแสดง
- อัปโหลดและจัดการรูปภาพหรือวิดีโอของชุดการแสดง
- จัดการบริบท หมวดหมู่ และคำสำคัญ
- จัดการบัญชีและสิทธิ์ผู้ใช้

### 3.4 เนื้อหาที่ไม่รวม

- การเผยแพร่ Artifact
- การตั้งค่าอีเมล
- การติดตั้งระบบ การดูแลเซิร์ฟเวอร์ ฐานข้อมูล หรือการพัฒนาโปรแกรม
- รายละเอียดทางเทคนิคของอัลกอริทึมแนะนำ

## 4. โครงสร้างเอกสาร

1. ปกเอกสาร
2. ข้อมูลเอกสารและประวัติฉบับ
3. สารบัญ
4. บทนำ: วัตถุประสงค์ กลุ่มผู้ใช้ ที่อยู่เว็บไซต์ สัญลักษณ์ และข้อกำหนดเบื้องต้น
5. เริ่มต้นใช้งาน: หน้าแรก เมนูหลัก การค้นหา และองค์ประกอบร่วม
6. คู่มือสำหรับผู้เยี่ยมชม
7. การสมัครสมาชิกและเข้าสู่ระบบ
8. คู่มือสำหรับสมาชิก
9. คู่มือสำหรับผู้ดูแลระบบ
10. การแก้ปัญหาเบื้องต้นและช่องทางติดต่อ
11. ภาคผนวก: คำศัพท์สำคัญและตารางสิทธิ์ตามบทบาท

ทุกภารกิจใช้โครงสร้างเดียวกัน:

1. วัตถุประสงค์
2. เงื่อนไขก่อนเริ่ม
3. ขั้นตอนพร้อมภาพหน้าจอและหมายเลขกำกับ
4. ผลลัพธ์ที่ควรเห็น
5. หมายเหตุหรือข้อควรระวังเมื่อจำเป็น

## 5. ระบบภาพและรูปแบบ

- ใช้โทนสีกรมท่า ทอง และครีมให้สอดคล้องกับเว็บไซต์จริง
- ใช้ฟอนต์ Sarabun หรือฟอนต์ภาษาไทยที่เข้ากันได้และอ่านง่าย
- ใช้ลำดับชั้นหัวเรื่องที่ชัดเจนและนำไปสร้างสารบัญอัตโนมัติได้
- ใช้กล่องสีแยก “หมายเหตุ” “ข้อควรระวัง” และ “ผลลัพธ์ที่ควรเห็น”
- ใช้ภาพหน้าจอขนาดอ่านได้ชัด ไม่ย่อทั้งหน้าเมื่อรายละเอียดเล็กเกินไป
- ครอบตัดภาพให้เน้นเฉพาะส่วนที่สัมพันธ์กับขั้นตอน และใช้หมายเลขกำกับแบบเดียวกันทั้งเล่ม
- ปกปิดชื่อบัญชี อีเมล และข้อมูลส่วนบุคคลที่ปรากฏในภาพ
- ปกเอกสารใช้ชื่อ “คู่มือการใช้งานระบบแนะนำชุดการแสดงนาฏศิลป์ไทย” และระบุเว็บไซต์จริง

## 6. วิธีเก็บข้อมูลและภาพหน้าจอ

- ใช้เว็บไซต์จริง `thaiperform.fed.bpi.ac.th` เป็นแหล่งภาพและข้อความหลัก
- เก็บภาพผู้เยี่ยมชมจากสถานะไม่เข้าสู่ระบบ
- เก็บภาพสมาชิกและผู้ดูแลหลังผู้ใช้เข้าสู่ระบบในเบราว์เซอร์ด้วยตนเอง โดยไม่ส่งรหัสผ่านให้ผู้จัดทำ
- ใช้งานเว็บไซต์แบบอ่านอย่างเดียว ไม่เพิ่ม แก้ไข ลบ เผยแพร่ หรือยืนยันการเปลี่ยนแปลงข้อมูลจริง
- สำหรับขั้นตอนที่มีผลต่อข้อมูล ให้บันทึกหน้าจอก่อนยืนยันและอธิบายผลลัพธ์ที่คาดว่าจะเกิดขึ้น
- ตรวจชื่อเมนู ปุ่ม และลำดับขั้นตอนกับหน้าจอจริงและโค้ดปัจจุบันของระบบ

## 7. ความเป็นส่วนตัวและความปลอดภัย

- ห้ามแสดงรหัสผ่าน รหัสยืนยัน โทเคน หรือข้อมูลลับในเอกสาร
- ปกปิดข้อมูลส่วนบุคคลในภาพทุกภาพก่อนนำเข้าเอกสาร
- หลีกเลี่ยงการแสดงข้อมูลเชิงสถิติหรือข้อมูลผู้ใช้ที่ไม่จำเป็นต่อการสอนใช้งาน
- ไม่ดำเนินการลบรายการ เปลี่ยนสิทธิ์ผู้ใช้ หรือส่งแบบฟอร์มที่ทำให้ข้อมูลจริงเปลี่ยนแปลง

## 8. การตรวจคุณภาพ

- ตรวจความถูกต้องของทุกขั้นตอนกับเว็บไซต์จริง
- ตรวจความสอดคล้องของชื่อเมนู ปุ่ม และคำศัพท์ทั้งเล่ม
- เรนเดอร์ไฟล์ Word เป็นภาพทุกหน้าเพื่อตรวจข้อความตัด ภาพแตก ตารางล้น การแบ่งหน้า และตำแหน่งหัว/ท้ายกระดาษ
- ตรวจว่าภาพทุกภาพอ่านได้และไม่มีข้อมูลส่วนบุคคลหลงเหลือ
- ตรวจว่าสารบัญ ระดับหัวเรื่อง และเลขหน้าทำงานสอดคล้องกัน
- ตรวจว่าไฟล์ Word เปิดและแก้ไขได้โดยไม่มีคำเตือนเรื่องความเสียหาย

## 9. เกณฑ์ยอมรับ

งานถือว่าเสร็จเมื่อมีไฟล์ Word ที่:

1. ครอบคลุมภารกิจของผู้เยี่ยมชม สมาชิก และผู้ดูแลระบบตามขอบเขตที่อนุมัติ
2. ไม่มีหัวข้อการเผยแพร่ Artifact และการตั้งค่าอีเมล
3. ใช้ภาพหน้าจอจากเว็บไซต์จริงและปกปิดข้อมูลส่วนบุคคลแล้ว
4. ไม่อาศัยการแก้ไขข้อมูลจริงเพื่อจัดทำภาพประกอบ
5. มีรูปแบบสม่ำเสมอ อ่านง่าย และแก้ไขต่อใน Microsoft Word ได้
6. ผ่านการเรนเดอร์และตรวจทุกหน้าโดยไม่พบข้อบกพร่องด้านการจัดวางที่เห็นได้ชัด
